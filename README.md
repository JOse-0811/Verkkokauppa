## TEKNOLOGIAT
- PHP
- SQL
- HTML
- CSS
- JavaScript
## ASENNUS
1. Kopioi tiedostot htdocs-kansioon
2. Luo tietokanta phpMyAdaminissa
3. Tarkista että yhteys.php tietokantatiedot vastaa omasi tiedostoon
4. Avaa selaimessa http://localhost/projekti/etusivu.php
